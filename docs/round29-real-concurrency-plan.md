当前模板规则使10个情感首次设定回复、10个认知初次评分阶段回复无需模型，预计160次正常模型生成；max_attempts=2时理论最多320次外部请求。同一次适配器超时/429后的重试计入该上限，不再另开全局重试。fixture故意注入的2重试/1兜底不作为真实供应商预期值。45人工程余量已离线测过，初轮不自动付费跑45人；45人同样6轮为240次正常生成/最多480请求。
