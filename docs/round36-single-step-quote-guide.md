# 控制台核价：每次只做一步

## 当前唯一操作

打开 https://usercenter2.aliyun.com/home ，使用本人的**阿里云中国站**账号登录，确认是否看到“费用与成本”首页。只回复“已看到首页”，或页面的非敏感提示。

现在不点充值/付款/创建，不录入Secret，不需要发送截图、余额、账号、订单号或支付信息。若界面不同或无法访问，就反馈当前提示；不要转国际站、借卡或绕过验证。登录不是购买授权。

## 看到首页后，才逐屏进行的核价顺序

以下是后续字段清单，**不是让你现在一次做完**。Codex收到当前页面反馈后，每次只说明一个页面动作和应看到的结果。未登录实际账户前不猜按钮位置/菜单名称，不给可能直接创建收费资源的操作。

| 后续页面             | 届时只查看的字段                                                                     | 应留下的非敏感证据                                |
| -------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------- |
| 账户付款/充值说明页  | 账户站点、实名要求、可用渠道、银联/支付宝/微信的实际限制；不确认充值                 | 可用方式文字，或遮住账号/金额/订单/支付信息的截图 |
| SAE地域/规格预览     | Singapore是否可选、目标CPU/内存/最小实例、是否常驻且不缩容到0、网络/出口/HTTPS计费项 | 所选配置及费用预览，不点击创建/部署               |
| RDS PostgreSQL预览   | 同区VPC、版本、实际高可用规格/容量/连接、自动备份/PITR窗口及费用                     | 规格和含税/未税费用，首购与续费条件               |
| OSS异地存储说明/计价 | 另一地区可用性、私有访问/版本化/生命周期、存储/请求/流量/取回费                      | 费用明细和限制；不创建桶或开通付费资源            |
| 网关/HTTPS与日志告警 | 入口、证书/域名、NAT出网、日志保留/监控/通知单价                                     | 独立费用项，不能漏计或默认为免费                  |
| 每档完整费用汇总     | 月费、逐期/续费、税费、24个月累计、一次性费用、优惠条件                              | 去除账号/订单/支付信息后的完整明细                |

只有看到完整费用预览，才提出预算/购买决定。核价中若平台必须先创建付费资源、充值或填Secret才能继续，立即停下告诉Codex；不为了报价先产生账单。

核价入口为官方价格计算器 https://www.aliyun.com/price 。如果计算器不支持某项海外地域或续费预览，需官方售前/账户报价单，不能用国内地域价格代替。SAE、RDS、OSS、HTTPS能分别购买也不代表组合网络可用，技术预检与30人容量另验。

## 截图时才需要的遮挡

如果后续确需截图报价：保留地域、商品规格、数量、币种、计费周期、报价日期、优惠条件、首购与续费价格；遮住姓名、手机号、账号/客户ID、余额、订单号、支付信息、连接串和全部Secret。不要为核价分享参与者账号或对话。
