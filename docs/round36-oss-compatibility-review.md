# 备份兼容性审查：现有作业不能直接换OSS Endpoint

仅审查round35的实际脚本，不修改代码、不访问存储账户。结论：**当前S3参考实现不具备已验证的OSS兼容性，OSS上线为BLOCKED**。未获取最新官方API文档，下面原生映射是待核验的适配设计，不是已实现或已验证支持清单。

| 现有代码实际调用                          | 作用                                        | OSS适配必须解决的差异与验收                                                                          |
| ----------------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| get-bucket-location                       | 与AWS_REGION比较；空值映射us-east-1         | OSS地域命名/返回格式不能沿用AWS默认值；用目标SDK读取真实桶地域并与获批异地清单核对                   |
| get-public-access-block                   | 要求AWS四项开关全部true                     | 不假设OSS管理API存在四项同名开关；按OSS实际公共访问防护/ACL/策略实现等效不可公开门禁，能力不明则拒绝 |
| get-bucket-policy-status                  | 要求PolicyStatus.IsPublic=false             | 需核验OSS原生API/策略语义，拒绝匿名或不受控公网授权；不可为了兼容删检查                              |
| get-bucket-versioning                     | 必须Enabled                                 | 用原生版本化状态核验；历史版本生命周期和费用另外审计                                                 |
| put-object及server-side-encryption=AES256 | 上传客户端GCM密文及清单，同时请求服务端加密 | 使用OSS原生SDK/签名/加密参数，核验实际返回与存储元信息；不能仅假设x-amz参数等于OSS参数               |
| head-object                               | 当前只检查ContentLength                     | 长度相同不等于内容校验完成；OSS适配需实现下载SHA256与GCM认证恢复，必要时核对原生校验机制             |

额外边界：现有作业仅比较声明的源地区和目标地区，未核实源数据库物理地域；上传不等于真实异地恢复。生命周期未由作业安装，缺少24小时无成功备份的独立心跳服务；运行器依赖/调度、外部告警和恢复身份也未部署。

## 拟定适配接口与最小权限

平台确认后只在运维层新增存储适配器：检查地域/私有性/版本化/加密/生命周期、上传密文与清单、校验对象、按版本下载并验SHA256、受控恢复。复用现有AES256-GCM封装和PG17工具，不改实验逻辑或模型Adapter。

优先核验OSS原生SDK方案。确认其ACL、Bucket Policy、公共访问防护和加密能力能实现同等安全目标后，才制定最小权限：备份写身份仅写production前缀及必要只读安全状态；恢复读/解密身份另授；不授予公开访问或删除主库/修改桶安全策略权限。若相关能力不满足，停止OSS方案，核价一个可实际验证相同API与安全语义的兼容存储候选；不在没有支付/地域证据时随意改为第三个云平台。

## 真实验收清单（全部NOT RUN）

创建获批私有桶与独立运行器后，确认源/备份不同获批地区、TLS/证书、工作负载身份和最小权限；完成加密上传、对象版本/长度/校验和核对，再从目标地区实际下载到全新隔离数据库恢复。逐表计数、完整性、消息/状态/变量/模型日志、版本、参与者隔离和complete=true导出全部一致才通过。

另测权限不足、公开策略、错误地区、版本化关闭、上传中断、错误密钥和篡改、告警失败；不能静默跳过。每日调度、独立缺失心跳、30份日备份及获批月归档、旧版本到期、季度恢复都需现场证据。平台PITR另列账单和恢复验证，不用它替代独立备份。
