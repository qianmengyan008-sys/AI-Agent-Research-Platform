# 两年期部署决策：先确认平台与预算，不创建收费资源

2026-10-20（UTC+8）。最多比较两个方案。本报告不是订购单；当前没有获准的预算上限，也没有读取研究者的云账户或创建资源。保留现有免费体验配置，不将其用于正式收集。

## 建议先做的一个决定

优先核价 **方案B：阿里云中国站托管方案**，因为研究者现有支付渠道与Render账单要求存在障碍。但本次无法在线核实官方页面和具体账户资格，B仍是待核验候选，不宣称已经确认可付款或已取得报价。若研究者愿意且Render账户实际可付款，再选A。现在仅需回复“优先核价的平台 + 24个月总预算上限（人民币）”；这不等于批准购买。

## 两个方案

| 项目       | A：Render付费                                                           | B：阿里云中国站托管候选                                                                                                                          |
| ---------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Web        | 长期开启的付费Web；本轮预备Blueprint暂列Standard，不代表容量/预算已确认 | SAE托管容器应用，明确固定最小实例防休眠/缩容到0；需核实所选地域及产品是否满足该运行模式                                                          |
| PostgreSQL | 独立付费PostgreSQL；暂列Basic 1GB只是待评估起点                         | RDS PostgreSQL独立实例，容量、连接数、备份/PITR窗口按报价确认                                                                                    |
| 区域       | 目标Singapore；实际账户可选性待确认                                     | 先查新加坡；若产品不支持，不自动换区域，应由研究者决定邻近区域及伦理要求                                                                         |
| HTTPS      | 平台分配地址及证书；是否自定义域名另行确认                              | SAE入口/负载均衡、域名与证书及其费用需纳入报价，不能把域名/网关默认为免费                                                                        |
| 异地备份   | 平台PITR + 独立区域私有S3兼容存储，后者需单独核价                       | 平台备份 + 另一地区私有OSS；S3兼容性不等同于所有AWS管理API兼容，可能需OSS适配                                                                    |
| 支付       | 无法确认银联、支付宝、微信可直接满足该账户账单要求；用户已遇到绑卡障碍  | 必须使用本人合规中国站账户核实人民币充值/支付宝/银行卡选项、实名要求和海外地域购买权限；不把国际站支付方式当中国站，也不保证微信或所有银联卡可用 |
| 运维       | 平台负责托管底层；应用升级、权限、备份告警和季度恢复需指定维护人        | 平台负责SAE/RDS/OSS底层；同样需要应用维护人；若需厂商运维服务，其费用另列                                                                        |
| 主要风险   | 支付不可行、Workspace恢复窗口/费用、数据库规格是否足够、两年费用变动    | 账户支付及海外地域尚未核实、网络/模型接口可达性、HTTPS与存储适配、运维服务报价                                                                   |

没有建议购买一台无人维护的服务器。Codex可以在会话中协助配置和修复，但不是自动提供两年的值守运维服务；必须在正式预算中指定维护责任人或明确的托管运维服务。
