# 管理后台、参与者端与实施／测试计划

本轮只做 Step 6.1 数据库落地，以下页面和 API 测试均为后续计划；当前前端仍为健康检查骨架。

## 管理后台模块

实验列表／创建 → 模板草稿 → 条件及 Agent／路径／Prompt 绑定 → 发布校验。参与者管理只做创建编号、分配发布配置；观测页只读展示状态与对话；数据页创建、查看和下载导出任务。

运行中没有直接编辑 state 的表单。人工干预只能通过研究协议允许的 Admin Event，由后端验证权限、原版本和原因并审计；本轮 admin_event 只是数据库记录，未实现干预路由。运行参与者继续绑定旧版本，新草稿不能覆盖其条件、Agent 或 Prompt。

## 参与者页面

登录页 → 实验说明／研究协议要求的确认 → 对话与当前表单 → 完成反馈。刷新后加载自己会话和保存消息；生成中有等待／恢复提示；提交冲突后重读当前表单，不自动重复评分。

页面不显示内部阶段代码、变量对象、Validator 信息、系统日志、管理员规则、完整 Prompt 或供应商错误。Agent 身份展示来自固定配置。需要评分／确认时只展示研究方案要求的当前内容，不从模型文字解析数值或阶段。提供按研究协议的退出入口，后端取消待生成任务。

| ---------- | -------------------------------------------------------------------------------------------------------------- |
| 6.1 本轮   | ER、首批 schema、up/down、账本／事务、真实 PostgreSQL 集成测试；API／UI 不动                                   |
| 6.2 下一轮 | 配置发布／auth／当前投影／结构化提交／消息保存 API；补账号会话、任务、审计和导出任务迁移，接口与数据库集成验收 |

第十轮授权已允许数据库实现，不再沿用第九轮的数据库开发门禁；真实模型 not_run 不阻止本轮数据库测试，但仍阻止声称真实模型稳定或正式实验就绪。没有自动批准上线。

## 自动化测试计划与当前完成范围
